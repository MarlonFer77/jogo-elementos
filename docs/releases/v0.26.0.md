# Elementos v0.26.0 — Multiplayer e pós-batalha

- Novo lobby pixel art: criar sala, entrar com código e retomar a última partida.
- Tela de conexão com feedback real, validação e mensagens de erro.
- Sala de espera com código copiável e preparação dos dois jogadores.
- Layout adaptado para vertical, horizontal e teclado aberto.
- Pós-batalha com arena preservada, resumo dos ganhos reais, revisão de habilidades e revanche.
- Identidade salva, progresso e protocolo Multiplayer preservados.

Instale `app-release.apk` por cima da versão anterior, sem desinstalar.
O servidor gratuito pode demorar na primeira conexão após um período sem uso.
Em dois celulares: um jogador cria a sala e compartilha o código; o outro entra
com outro nome. Ambos preparam seus elementos para iniciar a batalha.
